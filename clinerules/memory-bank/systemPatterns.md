# System Patterns

## Architecture
Next.js App Router. Client wizard (`app/studio/page.tsx` + `stores/projectStore.ts`) → API routes (`app/api/scrape`, `app/api/muse/*`) → Muse gateway via `lib/muse/client.ts:callMuse`. Key NEVER persisted server-side.

## Key Decisions
- `byokHeaders(req)`: real BYOK key in `x-meta-key` always wins; else if server-only `META_API_KEY` set, placeholder `__SERVER__` falls back to it (judging mode, source:'server'); else throws 400 `Missing API key…`. Real key never logged/stored. (Demo/`DEMO` removed 2026-11-02 — no mock fallbacks.)
- Judging mode (temporary, env-only): `NEXT_PUBLIC_JUDGING_MODE=1` hides Key step (boot/new at `writer`, breadcrumb + PREV skip `key`), landing copy switches; `lib/judging.ts` holds only the flag + `__SERVER__` placeholder (no secret); `META_API_KEY` stays server-only. Delete both env vars → pure BYOK. See `JUDGING.md`.
- Project state: single Zustand object (`projectStore.ts`) + `projectId/projectName/newFreshProject/openProject`. NO autosave — studio boots fresh; explicit Save/Open only via `ProjectBar`.
- Library: text/config in localStorage `meta-studio-projects-v1` ({id,name,updatedAt,savedAt} + PersistedProject; blob: URLs stripped on save); footage in Dexie `meta-studio-clips` v3 (`blobs: key,projectId,sceneId,kind,assetId` + `prefs: key`). Keys `blobKeyForScene(pid,s,k)` / `blobKeyForAsset(pid,id)`. Open revokes live blob URLs first (leak/bleed guard), loads text, then re-attaches this project's Dexie blobs (assets → `getBlobsForProject` + URL map; scenes → `hydrateForProject`). Delete removes entry + `removeBlobsForProject`. One-time migration: legacy `meta-studio-project-v1` → "Recovered project" + `migrateLegacyBlobsToProject`, legacy slot cleared.
- Model adapters isolated in `lib/muse/{spark,voice,visual}.ts` — only files needing change for real gateway shapes. (`mocks.ts` deleted 2026-11-02 with demo mode.)
- `lib/muse/models.config.ts` + `config/pricing.ts` single source for model IDs, costs, table copy. Reasoning depth: `reasoningEffortForSpark()` returns `xhigh` for both writers (documented max both support) sent as top-level `reasoning_effort` on all Spark chat calls (master draft + retry, organize, revise).
- Vault: `lib/vault/webauthn-prf.ts` (register/authenticate with PRF extension, raw-bytes `eval.first`, `as any` casts for v9 browser API; two slots: device-bound biometrics + synced passkey, export/import of encrypted-only bundle) + `lib/vault/crypto.ts` (HKDF→AES-GCM, IndexedDB slots `vault`/`vault-passkey` storing ONLY {credId,iv,ct,baseUrl,kind}).
- Scraper: homepage + 8 de-duped about candidates, JS-shell detection (`needsJs`) with honest fallback message, story beats into `aboutSummary`/`aboutPoints`/`aboutSource`, merges across URLs. Main-page discovery (2026-11-01): `fetchSitemapPages()` (same-origin `/sitemap.xml`, ≤20 locs, skips nested indexes, 500KB cap) + `discoverSitePages()` (same-origin nav `<a>` links, asset-extension filter, keyword-prioritized, deduped by pathname, capped 12) into `ScrapeResult.sitePages` → merged across sites into `BrandKit.sitePages`. SSRF guard (2026-11-02): ALL outbound fetches go through `safeFetch()` — http(s)+80/443 whitelist, per-hop DNS blocklist (loopback/private/CGNAT/link-local metadata/IPv6 ULA; 30s host cache), manual redirects ≤3 re-validated each hop, `readCapped()` bounded body reads.
- Security baseline (2026-11-02): `next.config.js` `headers()` sets X-Content-Type-Options / X-Frame-Options DENY / Referrer-Policy / Permissions-Policy (camera, mic, geo off) / HSTS on all routes (CSP pending ffmpeg-wasm nonce pass). NO `images.remotePatterns` — app uses plain `<img>`; `/_next/image` must never be an open fetcher. next pinned to latest 14.2.x (14.2.35); residual 2026 criticals require Next 15.5.28+/16 — see activeContext Next Steps.
- Duration math: 10s batches ONLY (2026-10-31) — `DURATIONS` = 10/20/30/60s, `normalizeDurationSec()` in `config/platforms.ts` is the single gate (5→10, 15→20 round half-up, else nearest). `WORDS_PER_SEC=3.5` (35 words per 10s, 210 per 60s / ~210 wpm natural pace), `targetWordRange(duration)` gives target/min/max/hardMax. EQUAL 35-WORD SENTENCE-COMPLETE PARTS (2026-11-04, user request; widened to a 33–37 band same day — Meta.ai cadence instructions absorb the slack): master is drafted part-by-part (`buildMasterScriptPrompt` — N paragraphs × 33–37 words (`MIN/MAX_WORDS_PER_PART`, aim `WORDS_PER_PART=35`) × sentence-final; Spark self-counts at xhigh, `generateMasterScript` validates via `withinPartWordBand` + ONE diagnostic retry + `fitPartToWordTarget` band-aware backstop — in-band text kept verbatim, all in `lib/muse/spark.ts` + `lib/script-utils.ts`). Story splits via rewritten `splitScriptIntoBalancedBatches` (`lib/meta-sdk/prompts.ts`): paragraph fast-path (honors Spark-authored blank-line blocks when in-band & sentence-final) → sentence-greedy fill toward 35/part (reserves ≥1 sentence per remaining part — every part ends on a sentence) → word-proportional only when sentences < parts. `rebalanceBatches` + `splitScriptIntoBatches` deleted. `checkBatchBalance` warns on mid-sentence endings + out-of-band word counts. Store defaults `durationSec: 20`; cost estimate re-based to 20s.
- Demo mode REMOVED 2026-11-02 (user request): no `DEMO` key, no `?demo=1`, no mocks — missing key throws 400.
- Export stitch loader v3 (`lib/render/ffmpeg.ts`): class-worker ALWAYS same-origin absolute `${origin}/ffmpeg/ffmpeg-worker.js`; coreURL/wasmURL try local `/ffmpeg/` then unpkg + jsdelivr `@ffmpeg/core@0.12.10` pairs; `[loader v3]` tag + tail-log on load errors; `resetFFmpeg()` terminates worker before Retry. Self-hosted runtime in `public/ffmpeg/` via `scripts/copy-ffmpeg-core.mjs` (postinstall).

## Component Map
`KeySetup` → `ModelPicker` → `SourceHub` → `ConfigureStep` → `Storyboard` (3-way `storyMode`: People + app / Voices-only per-part Meta.ai prompts via `buildBatchTestimonialPrompt` (last part asks Meta.ai to stitch first), or per-part voice-only `buildVoiceBatchPrompt` + `VoiceMp3Card` MP3 uploads (last part asks Meta.ai to stitch MPs first); parts auto-balanced live via `splitScriptIntoBalancedBatches` (paragraph fast-path → sentence-greedy 35/part → word fallback; every part ends on a complete sentence for flawless Meta.ai stitching, no manual button/gates; per-part header shows "complete sentence ✅"); 🌐 screenshot gallery with Save-all/per-shot save) → `ExportStep` (stitch-ONLY page 2026-11-02: `stitchParts` joins separate Part MP4s via normalize+re-encode → final MP4, `stitchAudioParts` joins separate Part MP3/M4A/WAV via concat filter → final MP3 (single files pass through), or `KenBurnsExportCard` + `buildKenBurnsCommercial` joining N voice MP3s under motion → final MP4; SRT/txt/backup downloads REMOVED; a user-uploaded Meta.ai-stitched voice file (MP3/MP4, Dexie `{pid}:voice-stitched`) takes priority and skips the join — Ken Burns motion only. Renderer progress is ALWAYS phase-mapped 0-100 via `clampProgress01`/`setPhase` — never surface raw FFmpeg progress, which is indeterminate/negative for `-loop` still inputs, and hugely negative for concat-demuxer inputs (2026-11-01 video stitch report: `progress=-4810068` → "-481006800%"); the handler now also derives progress from event `time`/expected duration and stays monotonic, with the single funnel `emitProgress()` + render-side clamps in `ExportStep`/`KenBurnsExportCard` as the durable guard). `lib/screenshots.ts` for the website-shot gallery (`screenshotCandidates(urls, aboutSource, sitePages)` up to 12, `ShotImg` retry, `downloadWebsiteShot` fetch→blob→named download with open-tab fallback). Studio header: `ProjectBar` (New / Save+name / Open(n) / Delete + amber unsaved warning) — the ONLY persistence UI; studio boots fresh, PersistGate is migration-only.

## Critical Paths
- `POST /api/muse/script` → `generateScript()` → Spark chat → strict JSON parse → throws 400 on failure (no mock fallback since 2026-11-02).
- `POST /api/muse/revise` →Spark→ EditPlan {summary,steps,targets,estCost}; locked scenes excluded upstream.
- `POST /api/muse/validate` → GET /v1/models/{id} catalog checks + 1-token chat pings (Spark×2) + image ping → per-model ok/auth/fail. Never probes dead paths (/v1/audio/speech, /v1/sam/segment, /v1/video(s)/generations).
