# System Patterns

## Architecture
Next.js App Router. Client wizard (`app/studio/page.tsx` + `stores/projectStore.ts`) → API routes (`app/api/scrape`, `app/api/muse/*`) → Muse gateway via `lib/muse/client.ts:callMuse`. Key NEVER persisted server-side.

## Key Decisions
- `byokHeaders(req)`: real BYOK key in `x-meta-key` always wins; else if server-only `META_API_KEY` set, placeholder `__SERVER__`/missing/`DEMO` falls back to it (judging mode, source:'server'); else `DEMO` returns mocks, truly-missing/placeholder-without-server-key throws 400. Real key never logged/stored.
- Judging mode (temporary, env-only): `NEXT_PUBLIC_JUDGING_MODE=1` hides Key step (boot/new at `writer`, breadcrumb + PREV skip `key`), landing copy switches; `lib/judging.ts` holds only the flag + `__SERVER__` placeholder (no secret); `META_API_KEY` stays server-only. Delete both env vars → pure BYOK. See `JUDGING.md`.
- Project state: single Zustand object (`projectStore.ts`) + `projectId/projectName/newFreshProject/openProject`. NO autosave — studio boots fresh; explicit Save/Open only via `ProjectBar`.
- Library: text/config in localStorage `meta-studio-projects-v1` ({id,name,updatedAt,savedAt} + PersistedProject; blob: URLs stripped on save); footage in Dexie `meta-studio-clips` v3 (`blobs: key,projectId,sceneId,kind,assetId` + `prefs: key`). Keys `blobKeyForScene(pid,s,k)` / `blobKeyForAsset(pid,id)`. Open revokes live blob URLs first (leak/bleed guard), loads text, then re-attaches this project's Dexie blobs (assets → `getBlobsForProject` + URL map; scenes → `hydrateForProject`). Delete removes entry + `removeBlobsForProject`. One-time migration: legacy `meta-studio-project-v1` → "Recovered project" + `migrateLegacyBlobsToProject`, legacy slot cleared.
- Model adapters isolated in `lib/muse/{spark,voice,visual,mocks}.ts` — only files needing change for real gateway shapes.
- `lib/muse/models.config.ts` + `config/pricing.ts` single source for model IDs, costs, table copy.
- Vault: `lib/vault/webauthn-prf.ts` (register/authenticate with PRF extension, raw-bytes `eval.first`, `as any` casts for v9 browser API; two slots: device-bound biometrics + synced passkey, export/import of encrypted-only bundle) + `lib/vault/crypto.ts` (HKDF→AES-GCM, IndexedDB slots `vault`/`vault-passkey` storing ONLY {credId,iv,ct,baseUrl,kind}).
- Scraper: homepage + 8 de-duped about candidates, JS-shell detection (`needsJs`) with honest fallback message, story beats into `aboutSummary`/`aboutPoints`/`aboutSource`, merges across URLs. Main-page discovery (2026-11-01): `fetchSitemapPages()` (same-origin `/sitemap.xml`, ≤20 locs, skips nested indexes, 500KB cap) + `discoverSitePages()` (same-origin nav `<a>` links, asset-extension filter, keyword-prioritized, deduped by pathname, capped 12) into `ScrapeResult.sitePages` → merged across sites into `BrandKit.sitePages`.
- Duration math: 10s batches ONLY (2026-10-31) — `DURATIONS` = 10/20/30/60s, `normalizeDurationSec()` in `config/platforms.ts` is the single gate (5→10, 15→20 round half-up, else nearest). `WORDS_PER_SEC=3.5` (2026-11-01 user request — 35 words per 10s, 210 per 60s / ~210 wpm natural pace), `targetWordRange(duration)` gives target/min/max/hardMax; master draft is sized to the slot (buildMasterScriptPrompt + retry + `constrainToWordRange` backstop), so Story starts fitting and `fitsDuration()`/cadence are only safety nets. Store defaults `durationSec: 20`; mock/cost re-based to 20s.
- DEMO mode: `key==='DEMO'` → deterministic mock script/images; `?demo=1` enters without key.
- Export stitch loader v3 (`lib/render/ffmpeg.ts`): class-worker ALWAYS same-origin absolute `${origin}/ffmpeg/ffmpeg-worker.js`; coreURL/wasmURL try local `/ffmpeg/` then unpkg + jsdelivr `@ffmpeg/core@0.12.10` pairs; `[loader v3]` tag + tail-log on load errors; `resetFFmpeg()` terminates worker before Retry. Self-hosted runtime in `public/ffmpeg/` via `scripts/copy-ffmpeg-core.mjs` (postinstall).

## Component Map
`KeySetup` → `ModelPicker` → `SourceHub` → `ConfigureStep` → `Storyboard` (3-way `storyMode`: People + app / Voices-only per-part Meta.ai prompts via `buildBatchTestimonialPrompt`, or per-part voice-only `buildVoiceBatchPrompt` + `VoiceMp3Card` MP3 uploads; parts auto-balanced live via `splitScriptIntoBalancedBatches` — sentence-aware `rebalanceBatches`, no manual button/gates; 🌐 screenshot gallery with Save-all/per-shot save) → `ExportStep` (stitch parts via FFmpeg.wasm normalize+re-encode in `stitchParts`, or `KenBurnsExportCard` + `buildKenBurnsCommercial` joining N voice MP3s under motion → final MP4 + SRT/txt/backup). `lib/screenshots.ts` for the website-shot gallery (`screenshotCandidates(urls, aboutSource, sitePages)` up to 12, `ShotImg` retry, `downloadWebsiteShot` fetch→blob→named download with open-tab fallback). Studio header: `ProjectBar` (New / Save+name / Open(n) / Delete + amber unsaved warning) — the ONLY persistence UI; studio boots fresh, PersistGate is migration-only.

## Critical Paths
- `POST /api/muse/script` → `generateScript()` → Spark chat → strict JSON parse → fallback mock.
- `POST /api/muse/revise` →Spark→ EditPlan {summary,steps,targets,estCost}; locked scenes excluded upstream.
- `POST /api/muse/validate` → GET /v1/models/{id} catalog checks + 1-token chat pings (Spark×2) + image ping → per-model ok/auth/fail. Never probes dead paths (/v1/audio/speech, /v1/sam/segment, /v1/video(s)/generations).
