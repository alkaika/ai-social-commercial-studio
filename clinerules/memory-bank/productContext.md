# Product Context

## Why
Small businesses need high-quality social ads without expensive subscriptions or agencies. This studio is free; users pay Meta directly for only what they generate.

## Problems Solved
- Agency cost → one-click generation from existing website.
- Subscription fatigue → BYOK, pay-per-use, cost shown upfront.
- Editing skill gap → Guided Simple Mode: anyone done in <5 min, zero jargon.
- Trust → stateless proxy, passkey vault, plain-English errors with fallback paths.
- Platform fragmentation → one project, multi-aspect export with safe zones.

## How It Works
Key → Writer (factual table) → Sources (scrape/uploads/paste) → Configure (duration/platform/tone) → Generate script → Revise (edit/quick/AI chat, approve plan+cost, old-vs-new) → Export (MP4+SRT+txt+backup).

## UX Goals
- One main button per screen. Smart defaults (brand colors, captions ON, music ducked, 9:16).
- Type minimum: tap cards. Words like picture/words spoken/seconds.
- Manual edits free & instant; AI regen per-scene only; Approve cost BEFORE spend; Approve result AFTER preview.
- Fresh start every load; explicit Save/Open named library replaces autosave (unsaved = amber warning, refresh wipes).
